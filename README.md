# Megan Pearson - AI Leadership Portfolio

A modern, responsive portfolio website showcasing Megan Pearson's experience in AI engineering leadership, cross-platform team management, and AI security research.

## About

This portfolio positions Megan for AI leadership roles by highlighting:

- 20+ years of experience from pilot to tech leader
- Current role as AI Engineering Leader at Pitch
- Expertise in scaling AI infrastructure and cross-platform teams
- Research and development of AI security protocols
- Focus on AI privacy, data security, and ethical deployment

## Features

- **Modern Design**: Clean, professional interface with dark/light mode support
- **AI Security Manifesto**: Interactive component showcasing AI security research
- **Responsive Layout**: Optimized for all device sizes
- **Performance**: Built with Next.js 15 and optimized for speed
- **Accessibility**: WCAG compliant design

## Tech Stack

- **Framework**: Next.js 15 with App Router
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Deployment**: Ready for Vercel deployment

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the development server:

   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Sections

- **Hero**: Introduction and current focus areas
- **About**: Professional journey and leadership philosophy
- **Experience**: Detailed work history and achievements
- **AI Security**: Interactive manifesto with research areas
- **Contact**: Professional contact information and social links
